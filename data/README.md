# Данные для обучения

Используется **BANKING77** от PolyAI: англоязычные обращения по банковским
операциям, размеченные по 77 темам. Исходные CSV и список категорий сохранены
без изменений. Ревизия репозитория и SHA-256 каждого файла находятся в
[source.json](source.json).

Авторы: Iñigo Casanueva, Tadas Temčinas, Daniela Gerz, Matthew Henderson,
Ivan Vulić. Работа: [Efficient Intent Detection with Dual Sentence Encoders](https://arxiv.org/abs/2003.04807),
2020. [Исходный репозиторий](https://github.com/PolyAI-LDN/task-specific-datasets),
[карточка датасета PolyAI](https://huggingface.co/datasets/PolyAI/banking77).
Данные распространяются по [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/).
Лицензия MIT в корне относится к коду проекта, а не заменяет лицензию датасета.

В обучении текст приводится к нижнему регистру и Unicode NFKC; пробелы
нормализуются, адреса почты и длинные последовательности цифр маскируются.
Названия классов приводятся к нижнему регистру, завершающий `?` убирается.
Исходные файлы при этом не перезаписываются.

Из train удаляются повторы нормализованного текста, конфликтующие метки
одинакового текста и совпадения с текстами официального test. Для этой
проверки пересечений используются тексты test, но не его метки. Официальный
test остаётся целиком: 3080 строк. Затем train делится на обучение,
калибровку и выбор порога. Словари и IDF обучаются только на первой части.

Это данные для воспроизводимой учебной проверки. Они не представляют все
темы, языки и формулировки реальной службы поддержки. В BANKING77 также
описаны ошибки разметки: [исследование авторов анализа](https://aclanthology.org/2022.insights-1.19/).
