# Результаты проверки

Проверено 11 сентября 2026 года на Docker Desktop, ARM64, Python 3.12
и PostgreSQL 17. Числа ниже относятся к локальному стенду.

| Проверка | Результат |
|---|---|
| Тесты с PostgreSQL | **26 passed in 1.47s** |
| Ruff lint / format / uv.lock | Пройдены |
| Docker Compose | API, PostgreSQL, RabbitMQ, dispatcher и worker healthy |
| OpenAPI | Снимок совпадает с API, 13 путей |
| Seed дважды | Успешно |
| Runtime | pytest и Ruff отсутствуют |

Через HTTP проверены классификация, неуверенный ответ, русский текст,
исправление оператором, конфликт старого If-Match и экспорт разметки.
При остановленном RabbitMQ API приняло обращение. После возвращения очереди
оно обработалось. SIGKILL во время обработки привёл к двум попыткам worker
и **одной** зафиксированной классификации.

Отдельно выгружена реальная правка из демонстрационного API и запущено обучение
с этим файлом: одна запись добавлена в fit, размеры calibration/validation/test
не изменились. Проверена загрузка сохранённых весов с теми же прогнозами.
Проверочная версия не активировалась; стенд использует banking77-v1.

ML-проверки сверяют hashes датасета, отсутствие точных пересечений выборок,
защиту от изменённого артефакта и соответствие опубликованных метрик
прогнозам сохранённой модели. В тестовой выборке — 3080 строк, macro-F1
выбранной модели — 0.90345. Ограничения оценки описаны в [model-card.md](model-card.md).
