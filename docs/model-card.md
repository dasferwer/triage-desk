# Модель сортировки обращений

## Задача и область применения

Вход — короткое английское обращение о банковском продукте. Выход — одна из
77 тем BANKING77, три наиболее вероятных варианта и решение: маршрутизировать
автоматически или передать оператору. Модель не пишет ответ клиенту и не
совершает банковских операций.

## Данные и обучение

Зафиксирована ревизия BANKING77 из `data/source.json`. После нормализации
из исходных 10 003 строк train исключены 11 повторных или пересекающихся строк.
Распределение оставшихся данных:

| Часть | Строки | Для чего используется |
|---|---:|---|
| Fit | 7494 | Словарь, IDF и веса классификатора |
| Calibration | 1249 | Одна температура для масштабирования оценок |
| Validation | 1249 | Выбор модели и порога маршрутизации |
| Official test | 3080 | Итоговые метрики |

Разделение стратифицировано, seed 42 и 43. Нормализованные тексты не пересекаются
между частями; это проверяется тестом. Тексты официального test используются
для исключения точных совпадений из train, метки test — только для оценки.
Близкие по смыслу формулировки не группируются: отсутствие точных повторов
не доказывает отсутствие всех возможных зависимостей внутри датасета.

Базовая модель: ComplementNB с alpha=0.3 и TF-IDF слов/биграмм, до 25 000
признаков. Вторая: Logistic Regression с C=8 и дополнительными символьными
3–5-граммами внутри слов, до 30 000 признаков. Обе используют разреженные
матрицы. По validation macro-F1 выбрана вторая модель.

Скрипт сверяет извлечённые веса с прогнозами scikit-learn. После сохранения
он также сравнивает вероятности загруженного артефакта с исходной моделью.
Файл `evaluation.json` хранит версии, hashes выборок и метрики по классам.

## Калибровка и порог

Температура минимизирует log loss на calibration, не меняя порядок классов.
Для Logistic Regression она равна примерно 0.5864. Порог выбирается на
validation с шагом 0.005: нужен минимум 50 принятых ответов и нижняя граница
95% интервала Wilson не ниже 0.90. Если такого порога нет, все ответы идут
на ручную проверку.

У выбранной модели порог **0.385**. На validation принято 1223 из 1249
обращений; точность среди них — 91.74%, нижняя граница Wilson — 90.07%.
Это правило выбора на ограниченной выборке, а не гарантия точности каждого
ответа или будущего трафика. В том числе интервал не учитывает весь эффект
выбора порога из нескольких вариантов.

На official test: macro-F1 **0.90345**, accuracy **0.90325**;
автоматически принято **3018 из 3080** (97.99%), из них правильно 91.35%.
Для базовой модели: macro-F1 **0.77101**, coverage 64.38%, точность принятых
ответов 93.24%. Порог каждой модели выбран отдельно по одному правилу.

Эти числа описывают темы внутри BANKING77. Высокая уверенность не означает,
что обращение относится к знакомой предметной области. Дополнительно
проверяются заявленный язык, наличие кириллицы и знакомых слов; этого
недостаточно для полноценного определения языка и неизвестных тем.

## Что проверять на реальном потоке

Нужна собственная разметка с выборкой и автоматических, и спорных обращений.
Очередь ручной проверки смещена в сторону трудных примеров; доля исправлений
в ней не равна общей доле ошибок. В API статистики это указано явно.

Для русского языка нужен отдельный датасет и новая оценка. Для незнакомых тем
понадобятся примеры вне домена и проверка отказа от автоматического ответа.
Порог также стоит оценивать по отделам: ошибка в теме карты и ошибка в теме
подозрительной операции могут иметь разную цену.

Источники: [карточка BANKING77](https://huggingface.co/datasets/PolyAI/banking77),
[scikit-learn: calibration](https://scikit-learn.org/stable/modules/calibration.html),
[scikit-learn: утечки при подготовке данных](https://scikit-learn.org/stable/common_pitfalls.html).

## Независимые OOD и смена источника

[Замороженная проверка CLINC150](external-evaluation.md) обнаружила ошибочную
автомаршрутизацию 541/1800 небанковских запросов (30.06%). На 90 запросах трёх
заранее сопоставленных тем другого источника ошибка среди автоматических —
37/75 (49.33%). Модель и порог не менялись. Эти результаты ограничивают применение
вне исходного BANKING77; числа, интервалы и воспроизведение приведены в отчёте.
