# Независимая проверка OOD и смены источника

Команда: `uv run python scripts/evaluate_external.py`. Результат сохранён в
`external-evaluation.json`; пересчёт проходит тест на равенство с сохранённым отчётом.
Проверяется настоящий `Classifier.predict` из сохранённого `banking77-v1`, включая
язык, знакомые термы и исходный порог 0.385. Обучение, калибровка и выбор порога
не вызываются. Этот эксперимент выявляет ограничение, а не исправляет модель.

Источник — [официальный CLINC150](https://github.com/clinc/oos-eval), Larson et al.,
[EMNLP-IJCNLP 2019](https://aclanthology.org/D19-1131/), ревизия
`828f8093932c8fe6ca7936c3d2e52903b1c523de`. Авторы собирали английские
одноцелевые запросы через crowdsourcing. Исходные `data_full.json`, `domains.json`
и лицензия CC-BY-3.0 сохранены в `data/external/clinc150`; их SHA-256 и правило
выбора находятся в `source.json`. Лицензия данных не заменяется MIT проекта.

До первого inference зафиксированы все официальные test-примеры четырёх явно
небанковских доменов: кухня/рестораны, автомобиль/дорога, утилиты и small talk.
Получено 1800 OOD-примеров, по 450 на домен и 30 на каждый исходный intent.
CLINC `oos_test` не используется: неизвестная CLINC тема не обязательно неизвестна
BANKING77. Train/validation CLINC не используются, подвыборки по результатам нет.

Отдельная ограниченная проверка смены источника: `pin_change → change_pin`,
`report_lost_card → lost_or_stolen_card`, `exchange_rate → exchange_rate`.
Сопоставление задано в manifest до inference, по смыслу названий классов,
не по предсказаниям. Это 90 запросов по трём темам; перенос на остальные 74 темы
или весь банковский поток из этого эксперимента не следует. Даже эти таксономии
могут различаться деталями продукта и инструкций разметки.

| Проверка | n | Ручная проверка | Ошибочная автомаршрутизация / все строки | Ошибка среди автоматических |
|---|---:|---|---|---|
| OOD | 1800 | 1259: 69.94% [67.79; 72.02] | 541: 30.06% [27.98; 32.21] | 541/541: 100% [99.29; 100] |
| Три сопоставленные темы | 90 | 15: 16.67% [10.37; 25.69] | 37: 41.11% [31.51; 51.44] | 37/75: 49.33% [38.33; 60.40] |

В скобках — двухсторонний Wilson 95%. JSON содержит также coverage автомаршрутизации,
числа строк, причин отказа и интервалы каждого домена/intent. У OOD любая
автомаршрутизация в банковский intent считается ошибкой; качество угадывания
150 тем CLINC здесь не вычисляется. Ручная проверка не означает правильной
классификации. Исходная высокая BANKING77 accuracy не переносится на эти данные.

Тексты сравниваются со **всеми** исходными BANKING77 train/test, поэтому охвачены
fit, calibration и validation. Сохранённый артефакт не использовал feedback
(`dataset.feedback = null`); скрипт откажется проверять модель с feedback без
явного корпуса для проверки пересечений. Семейство — SHA-256 нормализованного
`clean_text`, затем последовательности слов без пунктуации. Межкорпусных
совпадений и внутренних повторов выбранных семейств нет. Эта проверка исключает
также точные и нормализованные повторы, но не все смысловые парафразы. Исходные
labels, порядок и hashes выбранных строк фиксируются до inference. Wilson
интервалы описательные: зависимость парафразов и множественные сравнения не
учитываются. Данные учебные, не production SLA и не русский язык.
